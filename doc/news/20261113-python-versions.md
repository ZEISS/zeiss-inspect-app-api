
ZEISS INSPECT uses Python 3.14 by default, but other Python interpreters can be used as described in [Adding and using specific Python versions](../howtos/python_versions/python_versions.md). This allows to install older versions for backwards compatibility or newer versions to keep up-to-date.
